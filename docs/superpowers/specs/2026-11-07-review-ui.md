# Review UI decisions

Match Copilot/VS Code rather than invent new branding. Use existing DSH theme aliases with dark fallbacks: canvas #1f1f1f, editor #181818, border #333333, text #cccccc, accent #0078d4, added #3fb950, removed #f85149. Body uses host sans font; code uses system monospace at 12px/20px. Compact 26–30px file rows, 4px corner radius, restrained one-pixel borders. Keep uses accent fill; Undo uses outlined neutral style. All buttons have focus-visible and descriptive aria labels.

Restore Checkpoint is placed before the existing completed turn-process heading because the host has no additive turnHead slot. It restores files to that turn's starting state and preserves the transcript. First click reveals inline confirmation and description including subsequent turns; second explicit Restore performs it. Show unavailable state for historical turns. Do not hijack user-message source decoration.

Clicking a conversation file opens sidebar for that turn and selects that path. Counts open the same turn. Call-level badge still supports focusing original call. Review pane must load detail/full hunks, not try rendering bodyless list summaries. Scope and session changes clear obsolete content and errors immediately, and async replies use generation/alive guard. Sidebar Keep/Undo scope follows selected turn; all-changes scope is explicitly labelled. Row undo addresses the selected checkpoint record id. Partial failures appear as a visible notice even when RPC returns ok:true.

Unified diff remains supported. Side-by-side pairs consecutive deleted/added runs by index, context on both sides, blank cells for missing lines. Separate scroll overflow per code viewport; responsive narrow pane can use unified mode. Navigation selects the next file and scrolls it into view without automatic looping. Full diff is shown in review pane; inline rows may retain preview truncation.
